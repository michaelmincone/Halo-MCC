# Original/default MCC map variants

Default-layout `.mvar` files and the original developer Forge presets for Halo 3,
Halo 4 and Halo: Reach. Source filenames, directories and bytes are preserved
from the installed MCC build. Recorded on 2026-10-20.

| Game | Files | Contents |
|---|---:|---|
| Halo 3 | 27 | Canonical default files, including the three official MCC additions |
| Halo 4 | 25 | 22 base-map defaults and the original Relay, Ascent and Settler Forge presets |
| Halo: Reach | 24 | 19 native-map defaults and the five original Forge World presets |
| Total | 76 | |

The original Forge World presets are Asylum, Hemorrhage, Paradiso, Pinnacle and
The Cage. Halo 4's three developer presets cover Impact, Erosion and Ravine.

Community maps, mode-specific alternatives, competitive layouts and duplicate
copies are excluded. Some defaults are stored in the game's
`hopper_map_variants/` folder; that source directory name is preserved.
`manifest.json` lists every selection with its display name, map ID, source
metadata title, selection basis, size, SHA-256 and Git blob SHA-1.

These are defaults from the installed MCC build. Some files retain legacy
metadata or revisions; for example, `default_snowbound_012.mvar` has the embedded
title `HC Snowbound`. This collection does not claim byte-identical launch-era
Xbox files.

Treat these archival copies as read-only originals and save edits as new
versioned outputs. No game was launched; in-game loading and gameplay remain
untested.
