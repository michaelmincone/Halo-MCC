# Stock MCC map variants

Original `.mvar` files copied from the local MCC installation into this private
repository, preserving each game, source directory, filename and file byte.
Recorded on 2026-10-20.

| Game | Files |
|---|---:|
| Halo 3 | 333 |
| Halo 4 | 388 |
| Halo: Reach | 277 |
| Total | 998 |

Each game retains its `map_variants/` and `hopper_map_variants/` directories.
The Reach collection includes the five `hr_forgeWorld_*.mvar` stock templates.
`manifest.json` records every file's size, SHA-256 and Git blob SHA-1.

The installed `haloreach/map_variants/Headstrong_Star.mvar` is a custom build and
is excluded. Generated maps, downloaded user maps and the historical custom
Breakneck sample are outside this stock collection.

These are archival copies. Treat them as read-only originals and create new
versioned outputs for editing. No game was launched, and this upload does not
establish in-game loading or gameplay behavior.
